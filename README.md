# 文机 PWA 配布手順

このフォルダはPWA配布の編集元です。`npm run build` がソースをまとめ、`dist/pwa/` に配布物一式を生成します。旧 `App-PWA/` フォルダとルートの単体HTMLは配布対象から外しました。

## 公開リポジトリへ配置する

1. `npm run build` を実行します。
2. `dist/pwa/` の中身すべてを公開用リポジトリのルートへコピーします。`index.html`、`.nojekyll`、`manifest.webmanifest`、`sw.js`、アイコンとJavaScript資源の相対位置を保ってください。
3. 公開用リポジトリの差分を確認し、Pagesの既存設定とURLを維持して更新します。
4. 公開後にChrome・Edgeのオンライン起動、オフライン再起動、Service Worker更新、390px幅を確認します。iPhone実機のSafariとホーム画面アプリは実機で別途確認してください。

アプリ本体・Service Worker・manifestは `./` から始まる相対URLです。公開先のルートとGitHub Pagesプロジェクトサイトのような `/repo/` 配下の両方で使えます。Service Workerはアプリ画面と、初回操作時に使うプロット・キャラクター・シリーズZIP・作品ZIP・章ZIP・`vendor/fflate.mjs` をインストール時にキャッシュします。コードは各画面・ZIP操作まで遅延読込されます。

更新版のService Workerは、開いている旧画面が閉じられた後に有効になります。画面とコードは同じ版のキャッシュを優先して読み込みます。別タブで同じ作品が更新された場合、古い画面からの保存は止まり、競合を表示します。必要な編集はコピーするかZIP・TXTで退避してから再読み込みしてください。競合内容によってはZIP書き出しができない場合があります。画像は1枚10MiBまで、ZIPの展開後データは合計256MiBまでです。

## シリーズ・作品・ZIP

文机の最上位の作業単位はシリーズです。通常モードの上部には「シリーズを切り替える」「シリーズZIPで保存」「新しいシリーズ」があり、同じ端末内に複数シリーズを保持して切り替えられます。シリーズへ戻ったときは、そのシリーズで最後に開いていた作品へ戻ります。

シリーズ内の作品管理は、プロット画面の「シリーズ設定」にまとめています。ここから「＋ 新しい作品」、各作品の「開く」「削除」、「現在の作品ZIPで保存」、「作品ZIP / 旧JSONを開く」を利用できます。単体作品ZIP `fumizukue-work-archive` v1 の形式は変更していません。

「シリーズZIPで保存」は、現在のシリーズに含まれるすべての作品を `fumizukue-series-archive` v1 として1つのZIPへまとめます。内部では既存の作品ZIPを `works/0001.zip` などとして保持し、manifestに作品一覧とSHA-256を記録します。現在のフェーズでは**シリーズZIPの読み込み・復元は未実装**です。復元や端末間移送が必要な作品については、プロット画面から単体作品ZIPも保存してください。

`Ctrl / ⌘ + S` は通常モードではシリーズZIPを保存します。章ワークスペース中は章ZIPを保存します。

## 章ZIPと章ワークスペース

Phase 1では、作品全体をマスターとして保持しながら、任意の1章を `fumizukue-chapter-archive` v1 の章ZIPとして保存できます。プロット画面の各章にある「章ZIP保存」から書き出すか、章ワークスペース中は上部の「章ZIPで保存」または `Ctrl / ⌘ + S` を使います。

「章ZIPを開く」で章ZIPを選ぶと、その章だけを端末内へ置いた軽量な章ワークスペースとして開きます。サイドバーには `catalog.json` に含まれる作品全体の章名・話数・文字数が表示され、読み込まれていない章は区別されます。読み込まれていない章を選ぶ場合は、その章の章ZIPを指定します。Phase 1は同時に1章だけを保持する仕様で、複数章の追加読み込みは後続フェーズです。

章ワークスペースでは次のデータだけ編集できます。

- 読み込み済み章の章タイトル
- その章の話・本文
- その章のシーン・シーン画像

作品名・作品概要・詳細概要・キャラクター設定・人物画像はマスター作品の共有データとして参照専用です。特に詳細概要は通常版では `localStorage` にあるため、章モードでは読み込まず編集もしません。章ZIPには `sourceWorkId`、`chapterId`、`baseChapterHash` を保持しており、後続フェーズで編集済み章をマスターへ安全に戻すための競合検出に利用します。Phase 1ではマスターへの再統合、複数章ワークスペース、全体ZIP v2からの選択読み込みはまだ実装していません。

章ワークスペース中はシリーズ切替・新しいシリーズ・シリーズZIP保存・シリーズ内の作品切替を無効にします。通常モードへ戻るときは、編集した章ZIPを先に保存したうえで、上部の「マスター作品ZIPを開く」から元の作品ZIPを読み込んでください。フル作品を読み込むと章ワークスペース情報が解除されます。

## 旧版から移行して新ZIPを作る

旧版は作品JSONとlocalStorageの復元用コピー、新PWAはIndexedDBとZIPを使います。旧版にはZIP出力がないため、公開更新前に旧版を開き、「JSON書き出し」で作品JSONを保存してください。新PWAを同じブラウザ・同じ公開URLで開いたときに旧復元用コピーが見つかったら内容と日時を確かめて復元します。案内が出なければ、プロット画面の「作品ZIP / 旧JSONを開く」から旧JSON version 1〜3を読み込みます。

作品と画像を確認したら、プロット画面の「現在の作品ZIPで保存」で単体作品ZIPを保存し、必要な作品をすべてシリーズへ追加した後に「シリーズZIPで保存」も実行してください。単体作品ZIPは現在の復元・移送用、シリーズZIPはシリーズ全体の一括バックアップ用として保管します。

## ローカル確認

プロジェクトルートで実行します。

```powershell
npm.cmd run build
npm.cmd run serve:pwa
```

ChromeまたはEdgeで `http://127.0.0.1:4174/repo/` を開くと、ビルド済み `dist/pwa/` がサブパス配信されます。

## 公開先と端末データ

現在の公開先は[文机](https://jueyuedao-ship-it.github.io/novelwrite-pwa/)（[公開リポジトリ](https://github.com/jueyuedao-ship-it/novelwrite-pwa)）です。ローカルビルドはこの公開リポジトリを変更しません。

作品データは公開URLとブラウザの保存領域に結びつきます。ドメイン、プロトコル、ポートが変わると別の保存領域になるため、移送する作品は単体作品ZIPを書き出して新しいURLで取り込んでください。

### Safariとホーム画面アプリ間で移す

iPhoneではSafariとホーム画面に追加したWebアプリの保存領域は共有されません。WebKitによると、ホーム画面アプリの作成時にコピーされるのはCookieだけで、IndexedDBなど他のローカルデータはコピーされず、作成後も他のWebサイトデータは共有されません（[WebKit: Safari 17.2のWebアプリとCookie](https://webkit.org/blog/14787/webkit-features-in-safari-17-2/)）。文机の作品データはIndexedDBに保存されるため、同じURLを開いても自動では移りません。

Safariからホーム画面アプリへ移す場合は、Safari版のプロット画面で「現在の作品ZIPで保存」を押し、ダウンロードしたZIPを共有シートから「ファイルに保存」します。ホーム画面アプリを開き、必要なら新しいシリーズを作成してから、プロット画面の「作品ZIP / 旧JSONを開く」でそのZIPを選びます。作品を置き換える確認が出たら、内容を確認して読み込みます。

ホーム画面アプリからSafariへ戻す場合も同じ手順です。ホーム画面アプリで単体作品ZIPを書き出して「ファイル」に保存し、Safariで文机を開いてプロット画面から取り込みます。シリーズ全体を移送する場合は、シリーズ内の各作品について単体作品ZIPを保存してください。シリーズZIPの読み込みは今後のフェーズで追加予定です。
